Security notice — read first

This page is static. It has no login and cannot protect anything by itself — hiding it with CSS or JavaScript would not be real security. Protect the /admin/ folder on your server (HTTP Basic Auth via .htaccess/.htpasswd, Cloudflare Access, Netlify/Vercel password protection, or a separate authenticated backend). See docs/DEPLOY.md.

It only edits public identifiers (publisher IDs, ad unit IDs, placement keys). Never enter API secrets, passwords or payment details. Changes go live only after you download ad-config.json and upload it to the site root (and rebuild the Android app for Android). “Save preview” stores a draft in this browser only; test it by opening the game with ?adpreview=1.
