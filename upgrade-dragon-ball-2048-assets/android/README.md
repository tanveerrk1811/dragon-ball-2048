# Dragon Ball 2048 — Android project

Open this folder in Android Studio. See `docs/ANDROID_BUILD.md` (build), `docs/ADMOB.md` (ads), `docs/COMPLIANCE.md` (policies).
The game lives in `app/src/main/assets/www` (synced from the website project with `sync-web.sh`; includes the same `ad-config.json`).
Adsterra has no official Android SDK, so only AdMob is integrated. This project has not been compiled in the authoring environment (no Android SDK available).
